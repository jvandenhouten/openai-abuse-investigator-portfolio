# Upload Instructions

The GitHub repository already contains an initial README and Python `.gitignore`.

## Browser Upload

1. Download and extract the repository starter ZIP.
2. Open the GitHub repository.
3. Select **Add file** → **Upload files**.
4. Drag the extracted files and folders into the upload area.
5. Permit `README.md` to replace the temporary initial README.
6. Use commit message: `Add synthetic investigation dataset and portfolio dashboard`
7. Commit directly to the `main` branch.

## After Upload

The repository should show:

- `app.py`
- `requirements.txt`
- `data/`
- `database/`
- `docs/`
- `scripts/`
- `sql/`

Do not upload the ZIP file itself into the repository.
