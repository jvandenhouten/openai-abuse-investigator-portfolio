# Investigation Methodology

## Workflow

1. Intake and allegation framing
2. Initial triage and risk prioritization
3. Evidence preservation and data-quality review
4. Entity resolution across accounts, devices, sessions, targets, and content
5. Timeline development
6. Pattern and behavioral analysis
7. Alternative-hypothesis testing
8. Confidence assessment
9. Findings and recommended actions
10. Detection, policy, and product-learning feedback

## Reusable Pattern Library

- shared infrastructure
- temporal bursts
- repeated target focus
- template or phrase reuse
- new-account creation bursts
- post-enforcement evasion
- escalating intent
- functional role differentiation
- cross-platform migration
- contextual false positives
- event or geographic proximity
- language obfuscation

## Evidentiary Discipline

Each finding should identify the source evidence, analytical method, confidence level,
alternative explanations, limitations, and whether further collection is required.
